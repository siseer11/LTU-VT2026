This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

```bash
1. Install packages

2. Add the connection url of your PostgreSQL database to an .env file at the root of the project (ex: DATABASE_URL="postgresql://movieApp:xxxxx@localhost:5432/movieAppPg")

3. Seed the database, by running : pnpm prisma db seed (to get the dummy data in)

4. Run the dev server : npm run dev (or with yarn, pnpm etc)
```

# The app uses NextJS + Prisma + PostgreSQL
